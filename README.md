# 抓蚂 · 节目单专用仓库

本仓库只保存公开频道数据、EPG 生成脚本和定时发布流程，不包含抓蚂应用源码。

频道来自 iptv-org，节目单使用固定版本 iptv-org/epg，每天北京时间 06:00、18:00 自动生成。Pages 配置为 gh-pages 分支根目录。

节目单：https://ivan-whatkuku.github.io/zhuama-epg/epg/guide.xml

覆盖及有效期：https://ivan-whatkuku.github.io/zhuama-epg/epg/manifest.json

上游线路可用性与节目单覆盖因频道而异；不提供历史视频回看。
